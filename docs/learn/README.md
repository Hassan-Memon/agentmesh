# Learn

A short teaching track for a Python developer meeting Node, Nest, Next, gRPC and message
brokers for the first time, using this repository as the worked example.

1. [Architecture walkthrough](01-architecture-walkthrough.md): why each box exists and the
   request path end to end.
2. [System design trade-offs](02-system-design-tradeoffs.md): scaling, failure modes,
   back-pressure, idempotency, what breaks first at 10x.
3. [Concepts](03-concepts/README.md): one file per concept with pointers into the code.
4. [Interview talk track](04-interview-talk-track.md): two-minute and fifteen-minute
   versions, numbers to quote, ten likely questions.
5. [Run it yourself](05-run-it-yourself.md): observe it, break it, extend it.

Read 01, then skim 03 as you meet each concept in the code, then 02 and 04 once the system
is familiar.
